# Branch naming

Name new feature branches `feature/<descriptive-name>` and new bugfix branches `bugfix/<descriptive-name>`.

When implementing work planned in Plan Mode, first check out `dev` and pull the latest changes from `origin`. Create an appropriately named feature or bugfix branch from the updated `dev`, implement and commit the changes, push the branch, and open a pull request against `dev`. The user reviews and merges pull requests in GitHub.
