# Branch naming

Name new feature branches `feature/<descriptive-name>` and new bugfix branches `bugfix/<descriptive-name>`.

When implementing work planned in Plan Mode, create an appropriately named feature or bugfix branch, commit the changes, push the branch to the remote, and open a pull request.

After merging a pull request and before implementing another plan from Plan Mode, check out `dev` and pull the latest changes from `origin`.
